# Sổ Tay Tiếng Trung

Ứng dụng học tiếng Trung cho người Việt, chạy hoàn toàn trên trình duyệt:

- Hơn 11.000 từ vựng HSK 3.0 (cấp 1 đến 7–9) có pinyin, nghĩa tiếng Việt và âm Hán Việt
- Ôn tập lặp lại ngắt quãng, luyện tập, luyện viết chữ, phát âm
- Khẩu ngữ, thành ngữ, tục ngữ, hội thoại, ngữ pháp
- Đề thi thử HSK 2.0 và HSK 3.0 có file nghe thu sẵn

Mở `index.html` để dùng. Tiến độ học được lưu trong trình duyệt của mỗi người.

`so-tay-tieng-trung.html` là bản gốc; `index.html` là cùng nội dung có thêm khung HTML chuẩn để đăng web.
